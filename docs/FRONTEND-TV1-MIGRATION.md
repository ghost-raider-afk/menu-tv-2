# Frontend ТВ МЕНЮ 2 — визуальная база ТВ МЕНЮ 1

## Решение

Визуальным и UX-источником нового frontend ТВ МЕНЮ 2 является актуальный frontend проекта ТВ МЕНЮ 1.

ТВ МЕНЮ 1 используется только как источник интерфейсных решений и не изменяется.

Техническое runtime-ядро остаётся новым модульным ядром ТВ МЕНЮ 2:

```text
HTML
  -> TV1 visual shell
     -> core/
     -> components/
     -> pages/
     -> editor/
        -> API ТВ МЕНЮ 2
           -> PostgreSQL / SFTPGo
```

## Что переносится из ТВ МЕНЮ 1

- узкий основной `ui-rail`;
- контекстная панель `ui-context`;
- карточка текущего пользователя внизу контекстной панели;
- плотность интерфейса, панели, карточки, формы и таблицы;
- структура рабочего пространства;
- визуальная система редактора;
- страница входа;
- фирменный жёлтый акцент `#F4C915` как новый дефолт;
- адаптивное поведение rail/context.

## Что НЕ переносится из ТВ МЕНЮ 1

- старые API-вызовы;
- старое хранилище данных;
- старое состояние приложения;
- серверная логика;
- зависимости, которые дублируют новое ядро ТВ МЕНЮ 2.

## Shell

`shell.js` является единственным владельцем глобальной компоновки авторизованного интерфейса.

Он создаёт:

```text
ui-rail | ui-context | workspace
```

и верхнюю панель быстрых действий внутри workspace.

Старые `sidebar` и `topbar` ТВ МЕНЮ 2 удаляются из DOM при инициализации shell и не участвуют в рабочем интерфейсе.

## Навигация

Основной rail:

```text
Логотип / Обзор
Мониторы
Каталог
Настройки
```

Контекст «Мониторы»:

```text
Торговые точки
Мониторы
```

Контекст «Каталог»:

```text
Продукция и тара
```

Контекст «Настройки»:

```text
Шаблоны
Настройки сайта
Профиль
```

Переходы являются обычными стабильными URL-маршрутами и не зависят от истории предыдущих кликов.

## Дизайн-токены

`css/tv1/tokens.css` — главный источник визуальных значений нового интерфейса.

Пользовательская настройка `accent_color` сохраняется. Для базы, где ещё хранится старый нетронутый дефолт ТВ МЕНЮ 2 `#2563EB`, frontend использует новый дефолт ТВ МЕНЮ 1 `#F4C915`. После явного изменения цвета пользователем применяется выбранное значение.

## Редактор

Редактор не возвращается к старой архитектуре ТВ МЕНЮ 1. Его логика остаётся новой:

```text
UI
 -> commands
 -> Editor State
 -> renderer
    -> Preview
    -> Final JPEG
```

Внешний вид редактора и рабочей области адаптируется под ТВ МЕНЮ 1 через `css/tv1/editor.css`.

## Правило дальнейшей разработки

Нельзя добавлять новую UI-логику в старый `style.css` или возвращать глобальный монолитный `app.js`.

Новые изменения идут только в:

- `css/tv1/*` — визуальный слой;
- `js/core/*` — инфраструктура frontend;
- `js/components/*` — общие UI-компоненты;
- `js/pages/*` — страницы;
- `js/editor/*` — редактор.

## Проверка

CI обязан проверять:

- полный граф ES Modules;
- наличие TV1 theme loader;
- наличие `ui-rail` и `ui-context`;
- удаление legacy sidebar/topbar runtime-shell;
- фирменные TV1 visual tokens;
- production Docker build;
- запуск чистого PostgreSQL/SFTPGo/app;
- доступность TV1 frontend-файлов внутри production container;
- вход, создание точки и монитора, загрузку редактора и SFTP smoke.
